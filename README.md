# dsh-cloud-sync-tools

DeepSeek Harness（DSH）的**云端同步面板**：把工作区与会话按项目归档到你的私有 Git 仓库，支持多设备转移、多仓库合并与增量备份；版本历史由 git 提交保存（GitHub 可查看、对比与恢复）。

> 这是**工具代码仓库（公开）**，不包含任何用户数据。
> 同步数据在你自己登记的私有仓库里；本工具不会自动连接任何仓库。

---

## 功能

- 侧边栏「同步」按钮 + 悬浮菜单，全部操作在 DSH 内完成；
- 按项目归档：`projects/<项目>/workspace/`（可读文件树）与 `sessions/<会话id>/`（会话文件）；
- 上传：工作区全量 + 勾选会话；每次上传产生一次 git commit（历史与恢复用 GitHub / git）；
- 下载：系统文件夹选择框选位置 → 镜像工作区 → 会话 cwd 改写 → 自动登记为新工作区；
- 云端与同步视图：按「工作区 → 会话」层级显示同步状态（一致 / 有未上传改动 / 仅云端 / 未上传…）；
- 多仓库：可登记多个私有仓库，逻辑上合并展示；上传时选择目标仓库，并**记住该工作区上次使用的仓库**（下次自动预选）；仓库如何划分由使用者自行决定（多工作区共用一个仓库、或一个工作区一个仓库都可以）；
- 大文件（>95MB）走 git-lfs；
- 一键安装 / 一键更新脚本。

## 环境要求

- Windows 10/11
- DSH 桌面版（已启动过一次，生成 `%USERPROFILE%\.dsh`）
- Git（需要能访问你的私有仓库：SSH key 或 HTTPS 凭据）
- 建议安装 git-lfs（大文件需要）

## 安装（新设备）

1. 获取本仓库（任选其一）：
   - 直接克隆：
     ```
     git clone https://github.com/<你的账号>/dsh-cloud-sync-tools.git D:\dsh-cloud-sync-tools
     ```
   - 或下载本仓库的 `install/一键安装.cmd` 单独运行，按提示输入本仓库地址（脚本会自动克隆）。
2. 双击运行：
   ```
   install\一键安装.cmd
   ```
   脚本会：把插件以 link 方式写入 DSH profile → 用 DSH 自带 pnpm 安装依赖 → 配置 longpaths / 提交身份 / main 分支。
3. **完全退出 DSH 并重新启动**（托盘也要退出）。
4. 打开侧边栏 **同步 → 仓库管理…**，**登记你自己的私有仓库**（填地址自动克隆，或填本机已有仓库路径）。
5. 可选：登记其它镜像仓库后，上传时可选择目标仓库。

> 安装器默认**不会**登记任何同步仓库；确需把本次克隆的仓库登记为同步仓库，可运行 `一键安装.cmd -RegisterRepo`。

## 更新（增量）

双击运行：

```
install\一键更新.cmd
```

流程：`git pull --ff-only` 拉取本仓库最新代码 → 若插件 `package.json` 有变化则自动在 DSH profile 里执行 pnpm install → 提示重启 DSH。
加 `-DryRun` 可只检查不执行。

## 版本历史与恢复

插件**不维护自己的备份目录**：每次上传就是一次 git commit，仓库里保留每个文件的完整历史（git 自动按内容去重）。

- 查看历史：GitHub 仓库 → Commits；或本地 `git log --oneline -- projects/<项目>/workspace`
- 查看某次提交的文件：GitHub 上进入该 commit 浏览，或 `git show <commit>:projects/<项目>/workspace/files/<文件>`
- 恢复整个项目到某次提交：`git checkout <commit> -- projects/<项目>`，然后提交并推送
- GitHub 也支持对单个 commit 或 PR 使用 **Revert** 生成反向提交

## 安全与边界

- **工具仓库 ≠ 同步仓库**：本仓库是公开的工具代码，插件不会自动把克隆位置登记为同步仓库；
- 只有登记了**同一私密仓库地址**的设备之间才能互相同步；
- 把工具转发给别人时，对方默认看不到、也连不上你的私有仓库；
- 不要把工作区放在 DSH 安装目录（如 `D:\deepseek`），更新器可能清理该目录。
