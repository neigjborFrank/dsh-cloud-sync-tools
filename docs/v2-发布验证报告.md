## 7. 验证过程中发现并修复的问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | 安装脚本 PowerShell 变量名大小写不敏感，`$NodeExe` 参数被 `$nodeExe` 覆盖 | 参数改名 `$NodePath` |
| 2 | profile `package.json` 带 BOM 时 Node 解析失败 | 安装脚本解析时剥离 BOM |
| 3 | 数据仓库克隆在 Windows 长路径下 checkout 失败 | 克隆加 `-c core.longpaths=true`；仓库级 `core.longpaths` 配置 |
| 4 | git 行尾归一化改变文件字节，换机后清单哈希校验失败 | `.gitattributes` 增加 `* -text`；新增 `tools/v2/repair-manifest.mjs` 修复历史数据（已对真实私有仓库执行） |
| 5 | 云端视图把"本地已有、云端未上传"显示成"仅云端（本地缺失）" | 视图状态修正为 `not-uploaded` |
