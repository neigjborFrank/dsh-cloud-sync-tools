## 三、本轮解决的问题

| 上轮遗留风险 | 解决方式 | 验证 |
|---|---|---|
| 下载总包含工作区 | 下载接口与 UI 增加「同时下载工作区」开关（`withWorkspace`） | S8 |
| DSH 内存缓存覆盖登记 | 改调 DSH 官方 `ctx.workspaceRegistry.create(path,title)`，内存与磁盘一致 | S5.5、S6.1 |
| 大文件不可恢复 | 大文件走 **git-lfs**（`workspace/large/`），下载自动恢复；LFS 不可用时才退回清单 | S4、S5.3、S11 |
| 跨机 cwd 映射 | 下载时改写会话日志首帧 cwd 并放到对应 projectKey 目录，DSH 按 cwd 自动归属 | S5.6、S6.2 |
| 7 天过期清理未实测 | 新增 `tests/prune_test.mjs`：10 天前备份被删、超 3 份删最旧 | 保留策略测试 |
| 会话多副本导致上传选错 | 上传按「当前项目 cwd」优先定位会话；下载时检测并提示其它目录副本 | S12、`downloadSession.duplicates` |

## 四、本轮发现并修复的问题

1. **同一会话多副本时上传会串项目**：下载到新位置后本机残留旧 cwd 副本，`findSessionDir` 可能返回错误副本，导致会话被上传到另一个项目目录。修复：上传时按当前项目 cwd 优先定位，云端仅保留预期项目（S12 验证）。
2. **测试过程本身暴露出云端项目串号**（修复后的回归项）：第一轮测试曾在云端产生 `...machineA-test` 项目，已随本轮清理。

## 五、剩余限制

| 限制 | 说明 |
|---|---|
| 界面点击流程 | 本轮只验证 HTTP API 与 mock 服务；原生选择框/复选框的点击需重启 DSH 后手动确认一次 |
| LFS 前置条件 | 其它机器 clone 仓库需安装 git-lfs，否则大文件是指针（下载时会报"需先执行 git lfs pull"） |
| 大文件备份 | `backups/` 只记录 `large.json` 清单，不回滚大文件内容；回滚后大文件以当前 `large/` 为准 |
| 并发上传 | 未测试多客户端同时上传（单用户场景） |
